═══════════════════════════════════════════════════════════════════════════════
ROOT CAUSE: CLOUDINARY API REJECTION
═══════════════════════════════════════════════════════════════════════════════

Cloudinary is returning HTTP 500, which likely means:

1. Upload preset name is invalid/doesn't exist
2. Upload preset is not set to "Unsigned"
3. Upload preset has restrictions rejecting this request
4. Cloudinary account has issues (rate limit, quota, etc.)
5. Base64 image format not accepted by preset configuration

HOW TO FIX
═══════════════════════════════════════════════════════════════════════════════

Step 1: Verify the Upload Preset
─────────────────────────────────
  1. Go to https://cloudinary.com/console
  2. Click "Settings" → "Upload"
  3. Find the preset name matching CLOUDINARY_UPLOAD_PRESET
  4. If not found → create new preset
  5. Verify settings:
     ✅ Preset Enabled
     ✅ Unsigned toggle ON
     ✅ No restrictive filters
     ✅ Allows image uploads

Step 2: If Preset Name is Wrong
────────────────────────────────
  1. Create correct unsigned upload preset in Cloudinary
  2. Note the exact preset name
  3. Update Netlify:
     $ netlify link                 # Link repo to site
     $ netlify env:set CLOUDINARY_UPLOAD_PRESET "new_name"
  4. Redeploy:
     $ netlify deploy --prod

Step 3: If Preset Settings are Wrong
─────────────────────────────────────
  1. Edit the preset in Cloudinary dashboard
  2. Toggle "Unsigned" to ON
  3. Remove any file type restrictions
  4. Save changes
  5. Test again
