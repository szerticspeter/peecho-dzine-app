1️⃣  RESOURCE TYPE NOT SET TO IMAGE
─────────────────────────────────────

Location: https://cloudinary.com/console
         → Settings (gear icon)
         → Upload tab
         → Find your preset
         → Look for "Resource type" or "Allowed formats"

Check for:
  ☑ Image  ← THIS MUST BE CHECKED
  ☐ Video
  ☐ Raw

If "Image" is NOT checked:
  • Click the checkbox ☑
  • Save changes
  • Try again

⏰ This is the #1 cause of uploads failing!


2️⃣  FORMAT WHITELIST EXCLUDING JPEG
────────────────────────────────────

Location: Same as above
         Look for "Allowed formats" field

What it might show:
  □ Empty (means allow everything) ✅ GOOD
  □ A list like: jpg, png, gif, webp ✅ GOOD (has jpg)
  □ A list like: png, gif, webp ❌ BAD (no jpg!)

If it shows formats and JPEG is not in the list:
  • Add "jpg" or "jpeg" to the list
  • Save changes
  • Try again

The function sends JPEG base64, so JPEG must be allowed.
