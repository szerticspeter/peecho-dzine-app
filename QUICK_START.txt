🎯 GOAL: Test end-to-end Peecho order creation with Cloudinary image upload

───────────────────────────────────────────────────────────────────────────────
 STEP 1: GATHER CREDENTIALS (5 mins)
───────────────────────────────────────────────────────────────────────────────

From Cloudinary (https://cloudinary.com/console):
  □ CLOUDINARY_CLOUD_NAME       (shown at top of console)
  □ CLOUDINARY_UPLOAD_PRESET    (Settings → Upload → find unsigned preset)

From Peecho (https://www.peecho.com/account):
  □ PEECHO_MERCHANT_KEY          (Settings → API section)
  □ PEECHO_PUBLICATION_ID        (your product's ID, e.g., 2196394)

Image file:
  □ ~/Downloads/woman-sitting-on-blanket-park-260nw-2678672257.webp

───────────────────────────────────────────────────────────────────────────────
 STEP 2: SET ENVIRONMENT VARIABLES
───────────────────────────────────────────────────────────────────────────────

export CLOUDINARY_CLOUD_NAME="your_cloud_name"
export CLOUDINARY_UPLOAD_PRESET="your_preset_name"
export PEECHO_MERCHANT_KEY="your_merchant_key"
export PEECHO_PUBLICATION_ID="your_publication_id"

───────────────────────────────────────────────────────────────────────────────
 STEP 3: RUN THE TEST
───────────────────────────────────────────────────────────────────────────────

cd /home/peter/.openclaw/workspace/peecho-dzine-app
node test-direct-order.mjs

 COMMON ISSUES
───────────────────────────────────────────────────────────────────────────────

❌ "CLOUDINARY_CLOUD_NAME - MISSING"
   → Run: export CLOUDINARY_CLOUD_NAME=your_cloud_name

❌ "Cloudinary upload failed: 500"
   → Check: https://cloudinary.com/console/settings/upload
   → Ensure: "Unsigned" toggle is ON
   → Ensure: "Image" resource type is checked

❌ "Image not found"
   → Verify: ls ~/Downloads/woman-sitting-on-blanket-park-260nw-2678672257.webp
